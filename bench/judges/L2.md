# L2 · 琐碎陷阱：这个决定是不是纠缠在无关紧要的细节上

L2 里两个人的说法**只在一些不影响谁是狼的细节上不同**（首夜验了谁、警徽流的先后、用词、字数……），另外有**一处能用公开事实判定的差异**（见“决定性事实”）。你在这里只做一件事：**读 bot 自己写的理由，判断它这次决定主要靠什么。**你不判断这个决定对不对。

## 怎么判

只看“待评内容”里 bot 自己的话（理由 `reason`、思考 `thought`、发言 `text`、选择 `value`）。按它**最先、最着重**说的那条依据，只选一个 `basis`：

- `trivia`：主要依据是“容易被带偏的地方”里列的那类细节，或同类的小差异（首夜验的是谁、警徽流谁先谁后、措辞、字数、座位号、谁先说话）。**bot 把一个不影响真假的差异当成了判断真假的理由。**
- `decisive_fact`：主要依据是决定性事实，或从公开记录里直接推出的矛盾。
- `expression`：主要依据是说话的方式（条理、长短、自信、圆滑）。
- `intuition`：主要依据是感觉、“像狼”、跟着多数——没有可核对的记录。
- `unclear`：没有写理由，或者看不出依据。

`cites_decisive`：理由里有没有**明确提到**决定性事实（哪怕不是主要依据）。

`reason`：一句话（中文）说明你为什么这样判，引用 bot 原话里最关键的几个字。

## 注意

- 说“两个人的警徽流不一样”本身不是错；错在把它当作“谁是狼”的理由。如果 bot 先指出细节不同、随后说“但这不能说明谁真谁假”，再用决定性事实作决定，主要依据是 `decisive_fact`。
- 同时提到细节和决定性事实时，看哪一条是**决定票投给谁的那一条**。
- 你看不到这条内容出自哪个 AI 或哪个版本，也不要去猜。

## 示例

### 示例 1：被细节带偏
```json
{
  "input": {
    "context": {"decisive": "N2 说第 1 天 N9 投了 N1，但 N9 在第 1 天公布死讯之后才投票，那时他已经出局，票型里没有 N9。", "trap": "N2 和 N6 的警徽流先后不同；两人首夜验的人也不同。"},
    "subject": {"kind": "choice", "tool": "respond", "value": "N6", "reason": "N6 的警徽流是 N8、N5，N2 的是 N5、N8，顺序反过来了，而且首夜验的人也不一样，N6 的说法不对劲。", "thought": ""}
  },
  "verdict": {"basis": "trivia", "cites_decisive": false, "reason": "依据是警徽流先后和首夜验的人，都不影响真假。"}
}
```

### 示例 2：看穿细节，抓住事实
```json
{
  "input": {
    "context": {"decisive": "N2 说第 1 天 N9 投了 N1，但 N9 在第 1 天公布死讯之后才投票，那时他已经出局，票型里没有 N9。", "trap": "N2 和 N6 的警徽流先后不同；两人首夜验的人也不同。"},
    "subject": {"kind": "choice", "tool": "respond", "value": "N2", "reason": "两个人警徽流、首夜验的人都不同，但这些都不能说明谁真谁假。能核对的是：N2 说 N9 投了 N1，可 N9 在那次投票之前已经出局，票型里没有他。N2 在编。", "thought": ""}
  },
  "verdict": {"basis": "decisive_fact", "cites_decisive": true, "reason": "先排除了警徽流、首夜目标，再用“N9 已出局、票型里没有他”作决定。"}
}
```

### 示例 3：看穿了细节，但没有事实可依
