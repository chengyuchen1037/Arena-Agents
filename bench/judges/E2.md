# E2 · 向人类学风格：哪一段更像这位真人

你会拿到：**一位真人玩家的几段发言**（“参考发言”），和**针对同一个局面的两段候选发言 X 和 Y**。请判断：**X 和 Y 里哪一段在说话风格上更像这位真人。**

## 怎么判

只比**风格**，不比内容对不对、立场是什么、谁更有道理：

- 句子的长短、节奏、一次说几句、是否爱铺垫；
- 语气和用词：口语化程度、常用的口头语、称呼、标点习惯；
- 篇幅：和参考发言的长度接近的更像；
- 是不是“像在做报告”（分点、排比、自报座位）——真人的参考发言里没有这种写法的话，带有这种写法的一方更不像。

`closer`：`X`、`Y`，或者两段差不多、分不出时写 `tie`。`confidence`：`high` / `medium` / `low`。`reason`：一句话（中文），指出最关键的 1–2 处风格差异。

## 注意

- 两段候选的顺序是随机的，不要因为它们排在前面或后面而偏向。
- 不要因为某一段写得“更好”就判它更像：要看像不像**这位真人**。
- 你看不到候选来自哪个 AI 或哪个版本，也不要去猜。

## 示例

### 示例 1
```json
{
  "input": {
    "context": {"reference": ["我昨天就说了，N5 不对。你们不信，行，今天看票。", "又在绕。投谁，说一句。"], "situation": "第 2 天，白天发言，局面没有新的信息。"},
    "subject": {"kind": "pair", "x": "我先把今天的情况分三点说明：第一，昨晚无人出局；第二，N5 的发言有两处前后不一致；第三，我建议大家今天重点关注 N5。", "y": "N5 还是不对。昨晚没人出局，说明什么你们自己想。我今天还投他。"}
  },
  "verdict": {"closer": "Y", "confidence": "high", "reason": "Y 短、直接、口语，和参考发言的口气一致；X 分三点陈述，像在做报告。"}
}
```

### 示例 2
```json
{
  "input": {

    "subject": {"kind": "pair", "x": "各位，我今天想多说两句。昨天的票出得有点急，我先说我的看法，不是针对谁，只是想把这件事讲清楚，然后听大家的。", "y": "N3。就他。"}
  },
  "verdict": {"closer": "X", "confidence": "high", "reason": "X 的开头“各位，我今天想多说两句”、解释性的语气和篇幅都接近参考发言；Y 太短太硬。"}
}
```
