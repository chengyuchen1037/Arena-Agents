# M2 · 对局记忆召回：bot 答对了早先发生的事吗

局面里先发生了很多事，最后主持人问了 bot 一个关于**早先事实**的问题。你会拿到：**问题**、**标准答案**（“应有的事实”），和 **bot 的回答**。请判断：**bot 的回答有没有正确地回忆出这条事实。**

## 怎么判

只比**事实**，不比文字好坏：

- `correct`：回答里的事实和标准答案一致（说法可以不同，座位 / 人 / 日期 / 次数要对）。
- `partial`：对了一部分（例如只答对了人、没答对哪一晚；或者答了两个人，其中一个对）。
- `wrong`：回答的事实和标准答案矛盾，或者张冠李戴。
- `no_answer`：没有回答，或回答是“不记得 / 不确定”，没有给出具体事实。

猜对也是 `correct`，但是回答里同时列出多个互相矛盾的答案、靠“全都说一遍”碰运气的，判 `wrong`。`reason`：一句话（中文），说明回答和标准答案哪里一致、哪里不一致。

## 注意

- 你看不到这条回答出自哪个 AI 或哪个版本，也不要去猜。
- 标准答案只用来对照，不要把它的措辞当作评分标准。

## 示例

### 示例 1
```json
{
  "input": {
    "context": {"question": "第 1 夜被狼人刀死的是谁？", "expected": "N7"},
    "subject": {"kind": "speech", "tool": "speak", "text": "第 1 夜出局的是 N7，公告里写了。", "value": null, "reason": null}
  },
  "verdict": {"recall": "correct", "reason": "答出了 N7，与标准答案一致。"}
}
```

### 示例 2
```json
{
  "input": {
    "context": {"question": "第 1 天放逐投票里，谁被放逐了？谁投了他？（只答被放逐者）", "expected": "N4"},
    "subject": {"kind": "choice", "tool": "respond", "text": null, "value": "N9", "reason": "我记得是 N9 被票出去了。"}
  },
  "verdict": {"recall": "wrong", "reason": "答的是 N9，标准答案是 N4。"}
}
```

### 示例 3
```json
{
  "input": {
    "context": {"question": "预言家在第 1 天和第 2 天分别报了谁的查验结果？", "expected": "第 1 天报 N6（好人），第 2 天报 N10（狼人）"},
    "subject": {"kind": "speech", "tool": "speak", "text": "第 1 天他报的是 N6，是好人；第 2 天的我记不清了。", "value": null, "reason": null}
  },
  "verdict": {"recall": "partial", "reason": "第 1 天对了，第 2 天没有答出。"}
}
```

### 示例 4
```json
{
  "input": {
    "context": {"question": "第 2 夜守卫守了谁？", "expected": "N3"},
    "subject": {"kind": "speech", "tool": "speak", "text": "这个我不记得了。", "value": null, "reason": null}
  },
  "verdict": {"recall": "no_answer", "reason": "没有给出任何具体事实。"}
}
```
