# L3 · 核心矛盾：这个决定主要依据什么

你在评一个狼人杀 bot 的**一次决定**（投票或发言）。局面里埋着一条**决定性事实**（见“决定性事实”）：它能从公告、票型、私聊或可见的发言里直接推出谁在说谎。你不判断这个决定对不对，只判断：**bot 自己写下的理由里，这个决定主要靠的是哪一种依据。**

## 怎么判

只看“待评内容”里 bot 自己的话（理由 `reason`、思考 `thought`、发言 `text`、选择 `value`）。按它**最先、最着重**说的那条依据归类，只选一个 `basis`：

- `decisive_fact`：主要依据就是决定性事实，或从公开记录里直接推出的同类矛盾（声明和公告对不上、不可能的行动、公布之前就知道的事……）。bot 要说得出是哪一条记录、哪一句话。
- `trivia`：主要依据是一个**不影响谁是狼**的细节：首夜验了谁、警徽流的先后、用词、字数、座位号、谁先说话、谁多说了一句……（见“容易被带偏的地方”）。
- `expression`：主要依据是**说话的方式**：条理清不清楚、说得长不长、够不够自信、语气像不像老手、“说得太圆滑 / 太简短所以可疑 / 可信”。
- `intuition`：主要依据是感觉、“像狼 / 像好人”、跟着多数、跟着警长、或者别人已经在投谁——没有一条可以去核对的记录。
- `unclear`：没有写理由，或者理由里看不出任何一种依据。

`cites_decisive`：bot 的理由里**有没有明确提到**决定性事实（哪怕它不是主要依据）。只提到“有矛盾”而没有说是哪一条，算 false。

`reason`：一句话（中文）说明你为什么这样判，引用 bot 的原话里最关键的几个字。

## 注意

- 不要因为这个决定“碰巧是对的”就判 `decisive_fact`：对的决定也可能是凭感觉或凭表达方式得出的。
- 不要因为理由写得长、写得有条理就判 `decisive_fact`：看它引用的是什么。
- 你看不到这条内容出自哪个 AI 或哪个版本，也不要去猜。

## 示例

### 示例 1：决定性事实
```json
{
  "input": {
    "context": {"decisive": "N2 报告第 2 夜验了 N5，但 N5 在第 1 夜就出局了（第 1 天公布），第 2 夜的查验名单里没有他。", "trap": "N2 和 N7 的发言都很有条理，记录都报了 N6 是好人。"},
    "subject": {"kind": "choice", "tool": "respond", "value": "N2", "reason": "N2 说第 2 夜验了 N5，可是公告里 N5 第 1 夜就出局了，死人不可能被验，N2 的记录是编的。", "thought": ""}
  },
  "verdict": {"basis": "decisive_fact", "cites_decisive": true, "reason": "理由直接引用了“N5 第 1 夜就出局了”和“第 2 夜验了 N5”的矛盾。"}
}
```

### 示例 2：说话方式
```json
{
  "input": {
    "context": {"decisive": "N2 报告第 2 夜验了 N5，但 N5 在第 1 夜就出局了（第 1 天公布），第 2 夜的查验名单里没有他。", "trap": "N2 和 N7 的发言都很有条理，记录都报了 N6 是好人。"},
    "subject": {"kind": "choice", "tool": "respond", "value": "N7", "reason": "N2 的发言又长又顺，像背好的稿子；N7 说得短，反而像真话。我信 N7，投 N2。", "thought": ""}
  },
  "verdict": {"basis": "expression", "cites_decisive": false, "reason": "依据是“又长又顺像背稿子”“短所以像真话”，没有提到任何记录。"}
}
```

### 示例 3：凭感觉
```json
{
  "input": {
    "context": {"decisive": "N4 在第 1 天的投票里声明“我投 N9”，但公布的票型里 N4 是弃票。", "trap": "N6 昨天发言没有信息，投票也只是跟多数。"},
    "subject": {"kind": "choice", "tool": "respond", "value": "N6", "reason": "直觉告诉我 N6 不对劲，跟着多数走的人往往是狼。", "thought": ""}
  },
  "verdict": {"basis": "intuition", "cites_decisive": false, "reason": "“直觉”“往往是狼”，没有可核对的记录。"}
}
```

### 示例 4：琐碎细节
```json
{
  "input": {
    "context": {"decisive": "N2 在公布死讯之前就把昨晚的死者说成“没了”。", "trap": "N2 与 N6 的警徽流先后不同，首夜验的人也不同。"},
    "subject": {"kind": "choice", "tool": "respond", "value": "N6", "reason": "N6 的警徽流把 N9 放在最后，和 N2 正好相反，这个顺序有问题。", "thought": ""}
  },
  "verdict": {"basis": "trivia", "cites_decisive": false, "reason": "依据是警徽流的先后顺序，与谁是狼无关。"}
}
```
