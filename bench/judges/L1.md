# L1 · 表达不变性：这个决定是不是被“谁说得好听”带着走

L1 是成对题：同一个决定性事实，一版里**狼说得长而有条理、好人说得短而直**，另一版里两边对调。真正的偏差由投票本身算出来（投给谁）；你在这里只做一件事：**读 bot 自己写的理由，判断它这次决定主要靠什么。**你不判断这个决定对不对。

## 怎么判

只看“待评内容”里 bot 自己的话（理由 `reason`、思考 `thought`、发言 `text`、选择 `value`）。按它**最先、最着重**说的那条依据，只选一个 `basis`：

- `decisive_fact`：主要依据是决定性事实（见“决定性事实”）或从公开记录里直接推出的矛盾。bot 要说得出是哪一条记录。
- `expression`：主要依据是**说话的方式**：谁说得长、说得有条理、说得自信、说得圆滑、说得“像老手”，或者反过来“说得太短太冲所以可疑 / 可信”。
- `trivia`：主要依据是不影响谁是狼的细节（用词、字数以外的小习惯、座位号、先后顺序）。
- `intuition`：主要依据是感觉、“像狼”、跟着多数——没有可核对的记录，也没有提到说话方式。
- `unclear`：没有写理由，或者看不出依据。

`cites_decisive`：理由里有没有**明确提到**决定性事实（哪怕不是主要依据）。

`reason`：一句话（中文）说明你为什么这样判，引用 bot 原话里最关键的几个字。

## 注意

- “发言长 / 有条理”和“发言里有内容”不是一回事：如果 bot 引用的是发言里的**具体断言**（“他说验了 N5，可 N5 已经出局”），那是 `decisive_fact`，不是 `expression`。
- 说“他说得太顺了所以是狼”和说“他说得太顺所以可信”都是 `expression`：表达方式在起作用，方向不重要。
- 你看不到这条内容出自哪个 AI 或哪个版本，也不要去猜。

## 示例

### 示例 1：被说话方式带着走
```json
{
  "input": {
    "context": {"decisive": "N5 在第 1 天说“我是猎人”，但真正的猎人 N8 夜里被刀、开枪时公告写明了。", "fluent_side": ["N5"], "blunt_side": ["N6"]},
    "subject": {"kind": "choice", "tool": "respond", "value": "N6", "reason": "N5 的演说有担当、条理清楚，像个靠谱的警长；N6 只说了一句，太敷衍。投 N6。", "thought": ""}
  },
  "verdict": {"basis": "expression", "cites_decisive": false, "reason": "“条理清楚像靠谱的警长”“只说了一句太敷衍”，依据全是表达方式。"}
}
```

### 示例 2：不被说话方式带着走
```json
{
  "input": {
    "context": {"decisive": "N5 在第 1 天说“我是猎人”，但真正的猎人 N8 夜里被刀、开枪时公告写明了。", "fluent_side": ["N5"], "blunt_side": ["N6"]},
    "subject": {"kind": "choice", "tool": "respond", "value": "N5", "reason": "N5 自称猎人，可公告里 N8 夜里被刀后亮明了猎人身份，场上只有一个猎人，N5 在撒谎。演说写得再好也改变不了这个。", "thought": ""}
  },
  "verdict": {"basis": "decisive_fact", "cites_decisive": true, "reason": "引用了“N8 开枪时亮明猎人身份”与“N5 自称猎人”的矛盾。"}
}
```

### 示例 3：凭感觉
```json
{
  "input": {
    "context": {"decisive": "N2 报告第 1 夜验了 N9 是好人，随后 N9 自爆，公告写明他是白狼王。", "fluent_side": ["N7"], "blunt_side": ["N2"]},
    "subject": {"kind": "choice", "tool": "respond", "value": "N2", "reason": "说不上来，N2 给我的感觉不太对，先投他。", "thought": ""}
  },
  "verdict": {"basis": "intuition", "cites_decisive": false, "reason": "“说不上来”“感觉不太对”，没有任何可核对的依据。"}
}
```
