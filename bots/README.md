# 默认 bot 库

这里是 Arena-Agents 随版本提供的 12 个默认 bot：Alice、Bob、Carol、David、Eve、Frank、Grace、Henry、Ivy、Jack、Kate、Leo。

每个 bot 一个文件夹，便于 diff：

```text
bots/<名字>/
├─ bot.json              名字、头像（头像是 20×20 像素头像的部件描述，固定，不随机）
└─ core/
   ├─ identity.md        身份：一两句话 + 背景（≤ 300 字）
   ├─ voice.md           说话方式：连贯的散文 + 3–5 句用「」标出的原话样本 + 一行 `篇幅：xx–yy 字`（≤ 600 字）
   └─ mind.md            分析方式与学习态度（≤ 400 字）
```

## 怎么用

- **首次运行**（数据目录里还没有 `bots/`，也没有 v0.13 的 `roster/`）时，这 12 个文件夹被复制成默认阵容；复制出来的 bot 都是“未初始化”，需要先点“初始化”才能开局。
- **从默认库导入**（玩家详情里的按钮，`POST /api/bots/{id}/import-default`）：用这里的某个 bot 整体覆盖当前玩家（名字、头像、底层设定）。
- 这里的文件只是**模板**：复制之后数据目录里的 bot 有自己的内部 id，之后怎么改都不会影响这里。

## 写法约定

- 12 份底层设定互不相同：篇幅区间、语气、分析方式都不同；前提都是“想赢”。
- 说话方式写成连贯的散文，不分点；原话样本不重复。篇幅区间落在 30–280 字之内（每条发言有 300 字的上限）。
- 分析方式用各自的话表达同一种态度——先看发生了什么，再听谁说了什么；说得漂亮不等于是真的；被结果打脸就改。**不写任何具体打法，也不写具体游戏的词汇**：游戏的内容只通过剧本进来，底层设定只说“这个人是谁、怎么说话、怎么想”。
- 文件是 UTF-8、LF 换行，以换行结束（`tests/test_bots_defaults.py` 会检查）。

## 初始化产出（L1 / L2）

笔记、规则要点、打法等是每个 bot 自己“初始化”得到的，不在这里。v0.14 发版前会用默认契约和剧本真实跑一遍初始化，人工审定后放进各 bot 的文件夹，并在 `bot.json` 里记录来源与哈希；用户改过契约或剧本后，这些 bot 会显示“需要重新初始化”。
