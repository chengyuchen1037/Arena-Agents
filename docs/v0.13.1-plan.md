## 0. 目标

v0.13.1 做六件事，前五件主要面向“接管”（人类玩一个座位）的体验，第六件改进 agent 的长期设定：

1. **软暂停**：接管时可以“喘口气”。点一下，正在进行的模型回答和工具执行照常做完，然后所有 agent（含主持人）停下；点“继续”才接着跑。同时，**人类在公共频道持有发言权时不限时**。
2. **颜色标记**：接管时可以给每个玩家标一种颜色（不写文字），玩家自己决定每种颜色的含义。
3. **思考记录**：玩家详情里加“思考记录”按钮，打开一个窗口，像聊天记录一样按时间显示这个 agent 的思考，不显示工具调用。
4. **头像编号与重置**：每个头像有一个编号，输入同一个编号就能得到完全相同的头像；详情面板里头像旁边可以重新生成。
5. **错误日志**：右上角一个入口，列出全部 LLM 调用和报错。
6. **记忆与性格**：记忆不再逐局累积复盘，而是每局结束后更新对 1–12 号玩家的“印象”；性格由主持人模型按固定格式生成“行为指引”，不再是长段描述；两者都有字数上限。

另外一项接管体验的修正：**投票等选择类请求先选、再点“提交”**，防止误点（G45）。

不做：新的剧本内容、新的 Provider 协议、对局格式升级（v5 不变，见 §2）。

## 1. 决策记录（G1–G45）

### 1.1 软暂停

| # | 决策 |
|---|---|
| G1 | **入口。** 接管栏改为 `🎮 正在扮演 3 · Carol  [⏸ 暂停 agent] [退出接管]`。只在**接管中且对局运行中**可用；软暂停后按钮变为 `[▶ 继续]`。顶栏原有的“暂停 / 继续”（硬暂停）不变。手机上这个按钮与接管栏一起留在首行。 |
| G2 | **语义。** 点击后立刻：① 关闭“思考闸门”，任何 agent（**包括主持人**）都不再发起新的模型调用；② 已经在流式返回的调用照常收完，随后这一批工具调用照常执行并提交到世界（工具执行是同步的，不会做一半）；③ 游戏时钟在点击那一刻冻结，发言权、请求截止、sleep 闹钟全部停表，人类不会在软暂停期间超时。**不取消任何调用，不浪费 token。** |
| G3 | **两个阶段。** 界面显示“⏳ 收尾中（还有 N 个回答）”，全部收完后变为“⏸ agent 已暂停”。停在闸门前的 agent，卡片状态显示“⏸ 暂停中”（新的 agent 状态 `held`）。收尾时间最长 = 单次调用超时（默认 120 s）+ 客户端重试；收尾中提供“立即暂停”链接，等于顶栏的硬暂停（会取消仍在途的调用）。 |
| G4 | **软暂停期间人类照常操作。** 世界的提交闸门保持打开：人类可以阅读、打字、发言、结束发言、作答、使用技能。人类的动作照常投递给 agent，但 agent 停在闸门前，等“继续”后一次性处理（合并成一条 DELTA）。 |
| G5 | **继续。** 恢复时钟、打开闸门；停住的 agent 先合并暂停期间收到的消息，再调用模型。收尾阶段也可以点“继续”（等于取消软暂停）。 |
| G6 | **不是新的对局状态。** `status` 仍为 `running`，软暂停是运行时的易失标志 `soft_pause`；硬暂停、终局、预算上限、`hold_game`、服务关闭都会清除它；服务重启后与现在一样恢复为“已暂停（硬）”。对局 v5 不加字段。 |
| G7 | **与其他控制的关系。** 接管 / 退出接管仍要求硬暂停（F2、F4 不变）；软暂停中点顶栏“暂停”即转为硬暂停（此时通常已无在途调用）；软暂停中点顶栏“继续”不可用（用接管栏的“继续”）。 |
| G8 | **看门狗。** 软暂停期间不触发看门狗、不累计冷场次数、不出冷场横幅。 |
| G9 | **只有人类看得到软暂停。** agent 不被告知（延续 F6）：它们只是“下一次思考来得晚了”；游戏时钟冻结，所以在它们看来时间没有流逝。 |

### 1.2 公共频道发言不限时

| # | 决策 |
|---|---|
| G10 | **范围。** 被接管座位在 `type=public` 的频道（本剧本即公共频道 `public`）**持有发言权**（发言队列 / `open_floor` 的 `turn` 模式）时，这一轮发言权没有截止时间，界面倒计时显示“不限时”。**条数、字数上限不变。** 按频道类型判断，不写死频道 id（保持引擎与剧本无关）。 |
| G11 | **不变的部分（F7 仍然适用）。** 其他频道（狼人频道、私聊）的发言权、自由讨论、所有请求（投票、拍刀、夜间行动）的截止时间都不变。需要更多时间思考投票时，用软暂停（G2 冻结时钟）。 |
| G12 | **结束方式。** 人类点“结束发言”，或用完条数。主持人主动 `close_floor` 仍然有效（规则动作）；但主持人不会因为时间被唤醒来收尾：等待人类发言期间算“未冷场”，看门狗不唤醒主持人（G13）。 |
| G13 | **看门狗。** Supervisor 的“是否安静”判断增加一条：被接管座位持有不限时发言权、或有待答请求时，系统不算安静。 |
| G14 | **实现要点。** 世界状态记录“不限时持有者”（接管时设置、退出接管时清除）；发言权激活时，持有者在其中且频道 `type=public` → `deadline=None`；`floor.granted` 账本条目带 `untimed: true`，重放据此不显示倒计时。需要同时处理：发言组暂停 / 恢复时的重新计时、接管 / 退出接管那一刻该座位已持有的发言权（退出接管后按剩余名义时长恢复计时）。 |
| G15 | **不告诉 agent（F6）。** 主持人和其他玩家的状态板里，这一轮发言权与平时显示一致：实现时核对状态板是否输出别人的剩余秒数；若输出，则对不限时的发言权显示名义时长，不显示“不限时”。 |

### 1.4 思考记录

| # | 决策 |
|---|---|
| G21 | **入口。** 点击头像打开的玩家详情面板，头部动作区加“🧠 思考记录”；主持人详情面板同样有。 |
| G22 | **窗口。** 在页面里打开一个大的独立窗口（不是浏览器弹窗，避免被拦截和重复处理令牌），可以与详情面板同时存在、可关闭、手机上全屏。内容像聊天记录：按时间从上到下，每次被唤醒一条分隔线（游戏时间、第几轮），下面是这次的思考气泡；最新的在底部，打开时滚到底部，向上滚动“加载更早的记录”。窗口打开期间每 3 秒拉一次新增内容（不新增 SSE 事件）。 |
| G23 | **显示什么。** 只显示两类：**思考**（模型返回的推理内容：DeepSeek `reasoning_content`、Anthropic thinking、OpenAI 推理摘要、`<think>` 标签）和**自言自语**（没有伴随工具调用的普通文字）。**不显示**工具调用、工具结果（因此也不显示发言内容本身，发言在信息流里看）。模型不返回思考内容时显示“该模型没有返回思考内容”。 |
| G24 | **数据来源。** trace 日志里的 `thought` / `content` 事件；新接口 `GET /api/agents/{id}/thoughts?before=&limit=`，从最新往前分页读取（不整文件加载，单个日志可达 20 MB）。只针对当前对局；导入时选择“不含日志”的对局显示为空。 |
| G25 | **防作弊。** 接管中**不能查看其他 agent 的思考**：按钮禁用并提示原因，服务端同样拒绝（409）。对局结束（`finished`）后解除限制，可以赛后复盘查看。未接管时（观战）随时可看。 |
| G26 | **修订 D5。** D5“思维链只写日志、从不发给界面”改为：思考内容仍不通过 SSE 推送、不进重放，但可以通过 G24 的接口按需查看；接口只对可信客户端开放（本机或带 `ARENA_API_TOKEN`）。信息流里“思维链与工具调用只写入日志”的提示文字相应修改。 |

### 1.5 头像编号与重置

| # | 决策 |
|---|---|
| G27 | **头像编号就是部件组合的编码。** 例如 `f03s05h12c07e04m02a09k03`（脸型、肤色、发型、发色、眼睛、嘴、配饰、配饰颜色依次排列）。同一个编号永远画出同一个头像（只要素材库里这些部件还在）。不用随机种子：现在的随机挑选依赖其他头像，种子无法复现。输入时不分大小写，允许空格和 `-` 分隔。 |

### 1.7 记忆：从“逐局复盘”改为“玩家印象”

| # | 决策 |
|---|---|
| G37 | **新的记忆结构**（文件名仍是 `N{k}.memory.md`，存档白名单不用改）：`## 战绩`（引擎维护，不变）、`## 印象`（除自己外每个座位一行：`- N5 Eve：……`，按座位号排序）、`## 经验`（自己的打法心得，最多 3 条）。**删除 `## 对局记忆` 段**，不再保存逐局复盘原文。替换 E16、E21 中“追加到对局记忆”的部分。 |
| G38 | **字数上限**（已确认，Q7）：每条印象 ≤ 80 字；经验 ≤ 300 字；整份记忆 ≤ 1500 字。服务端在三处统一执行：手动保存（超限拒绝并提示）、复盘写入与“完善”结果（超限截断）。 |
| G39 | **复盘改为“更新印象”。** 仍是终局后手动触发、每人每局一次、用座位自己的模型（E21 不变）。复盘调用的输入增加【你目前的印象】【你目前的经验】；要求输出 JSON `{"impressions":{"N1":"…"},"experience":["…"]}`，解析失败时按行格式 `N1：…` 兜底。提示词要求：结合本局表现修订每个人的印象，本局没有新信息的保留原样；**不写“他是狼 / 预言家”这类身份结论**（身份每局重发），写风格、可信度、习惯，可以写“拿到狼牌时爱悍跳”这类条件化的习惯。 |
| G40 | **合并规则。** 模型漏写的座位保留旧印象；未知 id 丢弃；每条截断到上限；整份**覆盖写**（不再追加）；战绩仍由引擎计算。印象以 `N{k}` 为键，名字只是标签，改名后自动更新。复盘完成后界面显示本次改动（旧印象 → 新印象），原始输出写进日志。 |

## 6. 测试方案

### 6.1 离线测试（pytest，全部不联网）

**软暂停：**
- 软暂停时在途调用照常完成，回答写入会话，随后的工具批次提交到世界；之后没有任何新调用（用会阻塞的假模型计数）。
- 收尾阶段计数正确：`draining(n)` → `held`；没有在途调用时直接 `held`。
- 软暂停期间游戏时钟冻结：发言权、请求、sleep 闹钟都不到期；继续后剩余时间不变。
- 人类在软暂停期间发言 / 作答成功；agent 收到的消息在继续后合并处理，只产生一次调用。
- 硬暂停、终局、预算上限、`hold_game`、服务关闭都清除软暂停；重启后为硬暂停；接管 / 退出接管在软暂停中仍被拒绝。
- 软暂停期间看门狗不触发、不累计冷场。
- 软暂停状态下的重试 / 定时唤醒同样停在闸门前。

**不限时发言权：**
- 人类座位在公共频道持有发言权：`deadline=None`，长时间不发言也不超时；条数 / 字数仍然限制。
- 狼人频道、私聊、请求仍按原时限；agent 座位在公共频道仍按原时限。
- 发言组暂停 / 恢复、接管 / 退出接管那一刻已持有的发言权，计时正确。
- 等待人类发言期间看门狗不唤醒主持人。
- 状态板对其他 agent 的显示与普通发言权一致（G15）。
- 重放：`untimed` 的发言权不显示倒计时，最终状态与快照一致。

**思考记录与错误日志：**
- 接口只返回 `thought` / `content`，不含工具调用；分页从新到旧；大日志文件不整文件读取。

## 7. 风险与已知限制

| 风险 | 应对 |
|---|---|
| 软暂停收尾慢（单次调用最长 120 s + 重试） | 显示剩余回答数；提供“立即暂停”（硬暂停） |
| 软暂停期间人类动作会让 agent 积压消息，继续后一次涌入 | 合并为一条 DELTA，只产生一次调用；这是预期行为 |
| 人类在公共频道长时间不发言，对局停滞 | 设计如此（G10）；看门狗不催；需要时人类自己点“结束发言” |
